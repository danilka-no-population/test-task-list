# Мои задачи

Простой и аккуратный список задач на React + TypeScript. Интерфейс адаптирован под мобильные устройства и десктоп, данные сохраняются в браузере — сервер и API не используются.

## Возможности

- Добавление задач через кнопку или Enter.
- Запрет пустых задач и строк из одних пробелов.
- Переключение задачи между активной и выполненной.
- Удаление задач с плавной анимацией.
- Фильтрация: все, активные, выполненные.
- Отдельные пустые состояния для разных фильтров.
- Сохранение задач и выбранного фильтра в `localStorage`.
- Восстановление данных после перезагрузки страницы.
- Адаптивная вёрстка без прокрутки страницы: список задач прокручивается внутри карточки.
- Доступное управление с клавиатуры и поддержка `prefers-reduced-motion`.

## Стек

- React 19
- TypeScript 6
- Vite 8
- Чистый CSS без UI-библиотек
- `localStorage` для хранения данных

## Запуск

Требуется Node.js `20.19+` или `22.12+`.

```bash
npm install
npm run dev
```

После запуска Vite выведет локальный адрес приложения в терминале.

### Сборка

```bash
npm run build
```

Готовая production-сборка создаётся в папке `dist`.

### Локальный просмотр сборки

```bash
npm run preview
```

### Проверка кода

```bash
npm run lint
```

## Хранение данных

Данные сохраняются локально в браузере:

- задачи — ключ `test-task-list.tasks.v1`;
- выбранный фильтр — ключ `test-task-list.filter.v1`.

При загрузке сохранённые данные проходят проверку. Повреждённые или некорректные записи не ломают приложение.

